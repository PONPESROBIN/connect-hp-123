PhoneLink
Kirim teks dan file antara HP dan PC langsung lewat Wi-Fi (WebRTC, peer-to-peer).
Tanpa server, tanpa akun, tanpa build. Satu file: `index.html`.
Deploy di Vercel
Upload folder ini ke repositori GitHub.
Di vercel.com pilih Add New > Project, lalu impor repositori tersebut.
Framework Preset: Other. Kosongkan Build Command dan Output Directory.
Klik Deploy.
Cara pakai
Buka link Vercel di HP dan PC (satu Wi-Fi, bukan Wi-Fi tamu).
Perangkat pertama: Start here, salin kode, kirim ke perangkat kedua.
Perangkat kedua: Join with a code, tempel kode, Make reply code, kirim balik.
Perangkat pertama: tempel kode balasan, klik Connect.
